# 🖥️ PC Building Simulator Game

An interactive educational game to learn about PC components and how to build a PC.

## 🎮 Features

- **Component Selection**: Choose from various CPU, motherboard, RAM, GPU, storage, power supply, and case options
- **Visual Feedback**: Watch your PC build come together in real-time
- **Cost Tracking**: Keep track of your total build cost
- **Educational**: Learn about different PC components and their prices
- **Completion System**: Build a complete PC by selecting all 7 essential components

## 🚀 How to Play

1. Browse available components in the left sidebar
2. Click on a component to add it to your build
3. See your selections appear in the PC case display
4. Track your spending and component count
5. Complete your build by selecting all 7 components
6. Click "Complete Build" to see your final PC summary
7. Use "Reset" to start over

## 🛠️ Components Included

- **CPU** (Central Processing Unit)
- **Motherboard**
- **RAM** (Memory)
- **GPU** (Graphics Card)
- **Storage** (SSD)
- **PSU** (Power Supply)
- **Case**

## 📊 Tech Stack

- HTML5
- CSS3 (Flexbox & Grid)
- Vanilla JavaScript

## 💡 Learning Outcomes

Players will learn:
- What each PC component does
- Typical component price ranges
- How components work together
- Basic PC compatibility concepts
- Cost-benefit decisions in PC building
